- **Nurse Care at Home:** Certified nursing for ICU management, post-operative care, wound dressing, and IV therapy.
- **Elderly Care Services:** Dedicated daily assistance, companionship, medication management, and vital monitoring.
- **On-Demand Care:** Quick medical visits starting at **₹350**.
- **Japa & Newborn Care:** Traditional and clinical mother & infant post-natal care packages.
- **Physiotherapy at Home:** Orthopedic, neurological, and post-surgery rehabilitation (₹800 - ₹1,500/visit).
- **Medical Equipment Rental:** Oxygen concentrators, CPAP/BiPAP, hospital beds, and patient monitors.

## 🚀 100% Free Hosting Deployment (GitHub Pages)

This project is built as a high-performance static website and can be deployed with **zero monthly hosting fees**.

### Quick Deployment Steps:

1. **Create a GitHub Repository:**
   - Go to [GitHub.com](https://github.com) and create a new repository (e.g., `vaidya24-web`).
2. **Push your code:**
   ```bash
   git init
   git add .
   git commit -m "Launch Vaidya 24 website"
   git branch -M main
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/vaidya24-web.git
   git push -u origin main
   ```
3. **Enable GitHub Pages:**
   - In your GitHub repo, go to **Settings** > **Pages**.
   - Under **Source**, select `Deploy from a branch` -> `main` branch -> `/ (root)` folder -> click **Save**.
4. **Configure Your Custom Domain:**
   - In **Settings** > **Pages** > **Custom domain**, enter your domain name (e.g. `vaidya24.in`).
   - Check **Enforce HTTPS** (GitHub provides free SSL automatically).
5. **DNS Setup (at GoDaddy, Hostinger, or Namecheap):**
   Add these DNS records to your domain provider:
   - **Type `A` Records** (pointing to GitHub Pages IPs):
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
   - **Type `CNAME` Record:**
     - Name: `www`
     - Value: `<YOUR_GITHUB_USERNAME>.github.io`
